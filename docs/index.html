VoiceBuddy

Install via 0install

0install run https://deejaytc.github.io/VoiceBuddy/voice-buddy.xml

Otherwise, grab the bootstrap installer from the latest release (VoiceBuddy-Setup.exe) — it installs 0install and subscribes to this feed.
